# Jarvis setup (about 10 minutes, one time)

## 1. Get an AI key
1. Go to console.anthropic.com and sign up.
2. Under **Billing**, add $5–10 of credit. Normal personal use costs a few dollars a month.
3. Go to **API Keys**, create a key, and copy it (it starts with `sk-ant-`).

## 2. Put Jarvis online (free, with GitHub Pages)
1. On github.com, click **+ → New repository**. Name it `jarvis` and set it to **Public**.
2. Click **uploading an existing file**, drag in every file from the zip, then click **Commit changes**.
3. Go to **Settings → Pages**. Under *Branch*, pick `main` and `/ (root)`, then click **Save**.
4. After about a minute your app is live at `https://YOUR-USERNAME.github.io/jarvis/`.

## 3. Install it
- **iPhone / iPad:** open the link in **Safari**, tap **Share → Add to Home Screen**.
- **Windows PC:** open the link in **Edge**, then go to **⋯ → Apps → Install this site as an app**. It gets a Start-menu icon.

## 4. First launch (on each device)
Tap **⚙︎**, paste your API key, and add your name and home city. Allow **microphone** and **location** when asked.

## Good to know
- Your key, tasks and saved preferences stay on each device. They are never put on GitHub.
- Calendar events have buttons for Apple Calendar, Google and Outlook, so they land in whichever calendar you choose.
- Email drafts open in the Mail app, Gmail or Outlook, ready to send.
- On iPhone, you can say "Hey Siri, open Jarvis" to launch it hands-free.
